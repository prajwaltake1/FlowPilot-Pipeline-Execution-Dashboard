# FlowPilot – Pipeline Execution Dashboard

## About the Project
FlowPilot is a web-based CPU instruction execution simulator developed as a Computer Organization and Architecture (COA) micro project. It helps students understand CPU instruction execution through an interactive dashboard.

The project allows users to select arithmetic operations, enter input values, and simulate instruction execution step by step.

## Features
- Simple and user-friendly interface
- Supports ADD, SUB, and MUL operations
- Accepts two input numbers
- Step-by-step instruction simulation
- Displays the calculation result
- Interactive web dashboard

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.
4. Select an operation (ADD, SUB, or MUL).
5. Enter the two numbers.
6. Click **Start Simulation** and use **Next Step** to proceed through the simulation.

## Example
- First Number: 8
- Second Number: 3
- Operation: ADD
- Result: 11
